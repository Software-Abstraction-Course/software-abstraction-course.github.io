    1D Mini Project 1

    Grouping

    You can do this project either individually or in groups of two persons. You can choose your own grouping. If you work as a group, you only need to submit one submission. Indicate all the team members in your racket file as a comment at the top of the submissions.

    Introduction

    The ultimate goal of this project is to create a language that can be used to work with tabular data. This can be used, for example, as a query language to create, read, update or delete data in a table. The goal of the first mini project is for you to be able to write various functions to manipulate individual values for number and string data. Think of this project as an equivalent of Excel or Pandas library in Racket.

    You are allowed to use the base package of Racket in this assignment.

    #lang sicp
(#%require racket/base)

    You can see the documentation for the functions available in this page.

    Task 1

    Choose 10 functions in Excel that deals with individual value in a cell. Consider only those functions that work with numbers and string data. Some examples are given below. Choose those that are not available in Racket base or has a different name or arguments.

    Here are some examples of the code you can consider:

    Numeric functions

    • TRUNC: Truncates a number to an integer.
    • SUMSQ: Returns the sum of the squares of the arguments. positive square root.
    • SIGN: Returns the sign of a number.
    • ROUNDUP: Rounds a number up, away from zero.
    • RAND: Returns a random number between 0 and 1.
    • RADIANS: Converts degrees to radians.
    • PRODUCT: Multiplies its arguments.
    • POWER: Returns the result of a number raised to a power.
    • MOD: Returns the remainder from division.
    • DEGREES: Converts radians to degrees.

    Strings function:

    • FIND: Finds one text value within another (case-sensitive).
    • LEFT: Returns the leftmost characters from a text value.
    • LEN: Returns the number of characters in a text string.
    • LOWER: Converts text to lowercase.
    • RIGHT: Returns the rightmost characters from a text value.
    • SUBSTITUTE: Substitutes new text for old text in a text string.
    • TEXT: Formats a number and converts it to text.
    • TEXTAFTER: Returns text that occurs after given character or string.
    • TEXTBEFORE: Returns text that occurs before a given character or string.
    • TEXTJOIN: Combines the text from multiple ranges and/or strings.
    • TEXTSPLIT: Splits text strings by using column and row delimiters.
    • TRIM: Removes spaces from text.
    • UPPER: Converts text to uppercase.
    • VALUE: Converts a text argument to a number.

    Task 2

    You are going to write tests before your function implementations. To do this, we will write Unit tests. Racket provides unit test library using RackUnit.

    • Read RackUnit Quick Start.
    • Create a new file called functions.rkt and functions-test.rkt.
    • Add the following to your functions-test.rkt. 
      #lang sicp

(#%require rackunit
           rackunit/text-ui
           "functions.rkt")

    In writing the test cases, look into the examples of the Excel functions. For example, the test cases for "FIND" function should be written at least by three test cases as shown below.

    (define test-find
  (test-suite
   "Test find"
   (check-equal? (find "M" "Miriam McGovern") 1 "Position of the first M")
   (check-equal? (find "m" "Miriam McGovern") 6 "Position of m case sensitive")
   (check-equal? (find "M" "Miriam McGovern" 3) 8 "Position of the first M after 3rd character")))

    Lastly, to run the test cases add the following line inside your functions-test.rkt. 

    (run-tests test-find)

    Task 3

    From those 10 that you have selected, write the equivalent functions in Racket. For each function, write a test function using Rackunit.

    You are allowed to use Racket's base functions if it is available and has a different name as the Excel functions.

    Task 4

    Write a bash script called runtests.sh to run all your tests. A simple example of a bash script is shown below.

    #!/usr/bin/env bash
racket functions-test.rkt

    Make sure the script is executable. If you need, change the mode to make sure it is executable using the command below.

    chmod a+x runtest.sh
